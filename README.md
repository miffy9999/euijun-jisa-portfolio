# 정의준 JISA 일본 인턴십 포트폴리오

리모트플러스에서 수행한 실시간 번역기 개발을 중심으로 채팅 서버 구축·배포 경험을 함께 정리한 정적 웹사이트입니다.

## 공개 주소

https://miffy9999.github.io/euijun-jisa-portfolio/

## 사용 방법

1. 이 폴더의 모든 파일과 `assets` 폴더를 GitHub 저장소의 루트에 업로드합니다.
2. 저장소의 **Settings → Pages**에서 `main` 브랜치의 `/ (root)`를 선택합니다.
3. 배포된 주소에서 한국어·일본어 전환, 모바일 레이아웃, 사진 공개 범위를 최종 확인합니다.

## 주요 구성

- 호텔 프런트·콜센터용 로컬 실시간 번역기
- Whisper STT · Hy-MT2 · 번역 메모리 · WebView2 Windows 앱
- NestJS · Socket.IO · PostgreSQL · Docker Compose · Caddy
- 한국어·일본어 전환 및 모바일 반응형 레이아웃

## 사진 사용 안내

사진은 정의준 학생의 활동 기록에 연결된 자료만 사용했습니다. 공개본에서는 서버 식별자·사내 화면·정기권 번호가 보이는 이미지를 제외하고, 개인정보가 없는 번역기 화면과 활동 사진만 사용했습니다.
