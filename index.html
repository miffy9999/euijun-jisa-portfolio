호텔 프런트와 콜센터의 실제 대화를 위해 고객 음성을 받아 원문을 인식하고 일본어 번역을 표시하는 로컬 프로그램을 개발했습니다. 직원의 일본어·영어 답변은 고객 언어로 다시 번역하며, 가타카나·로마자 읽기 보조도 같은 화면에 제공합니다.

ホテルフロントとコールセンターの会話に向け、顧客音声を認識して日本語訳を表示するローカルプログラムを開発しました。スタッフの日本語・英語の返答は顧客言語へ翻訳し、カタカナ・ローマ字の読み方も同じ画面に表示します。

CHAT SERVER · 30%

채팅 연동과

호텔 객실 고객과 콜센터 상담원을 연결하는 채팅에서는 서버 구조와 운영 배포에 집중했습니다. NestJS·Socket.IO·PostgreSQL을 Docker Compose로 구성하고, Caddy가 HTTPS와 실시간 연결을 처리하도록 Sakura VPS에 배포했습니다. 관리자·상담원·고객 화면의 데이터 흐름과 외부 통신도 함께 검증했습니다.

ホテル客室の顧客とコールセンター担当者を結ぶチャットでは、サーバー構成と運用配備に注力しました。NestJS・Socket.IO・PostgreSQLをDocker Composeで構成し、CaddyがHTTPSとリアルタイム接続を処理する形でSakura VPSへ配備。管理者・担当者・顧客画面のデータフローと外部通信も検証しました。

고객 음성은 외부 클라우드로 보내지 않고 PC 안에서 인식·번역됩니다. 확정 원문을 먼저 보여주고 번역과 읽기 보조를 순서대로 더해, 기다림을 줄이고 개인정보도 보호하도록 설계했습니다.

顧客音声は外部クラウドへ送らず、PC内で認識・翻訳します。確定原文を先に表示し、翻訳と読み方支援を順に追加することで、待ち時間を減らし個人情報も守る設計です。
